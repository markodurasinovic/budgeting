# budgeting

A budgeting app project.

## Status

The previous Rust implementation has been removed. The project is ready for a new application direction and technology stack.

## Product Goals

This project should help people understand and manage their spending with a small, practical set of workflows:

- record income and expenses
- categorize transactions
- review monthly totals
- import existing spending data
- spot changes in spending over time

## Next Steps

Before rebuilding the app, decide the new stack and target experience:

1. choose the application platform
2. define the data model
3. decide how transaction import should work
4. sketch the core budgeting workflow
5. add the new project scaffolding
